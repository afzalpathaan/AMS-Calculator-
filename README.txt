# AMS Calculator — PWA

This is the existing Analog & Mixed-Signal IC Calculator converted into an installable Progressive Web App.

Included:
- index.html — existing calculator UI/logic
- manifest.json — app installation metadata
- service-worker.js — offline caching
- icons/ — app icons

Important:
A PWA must be opened from HTTPS (or localhost) for installation/service-worker features to work.
